# Third-party components used by the foot platform

| Package | Use | Licence |
|---|---|---|
| `three` | 3D viewer, OrbitControls | MIT |
| `sharp` | Server-side image decode / resize / JPEG encode | Apache-2.0 (bundles libvips, LGPL-3.0, as dynamically linked binaries) |
| `qrcode` 1.5.4 | QR code for the phone link | MIT |
| `zod` | Request validation | MIT |
| `firebase-admin` | Firestore storage | Apache-2.0 |
| `next`, `react` | Framework | MIT |
| `playwright` (tests only) | Browser tests | Apache-2.0 |
| `tsx` (tests only) | Run TypeScript tests | MIT |

Not used (researched, see AI_MODELS.md): COLMAP (BSD), Polycam API (commercial), OpenCV, PyTorch, MiniDraco/footscan (not found).
All measurement and sizing code is original to this project. Sample photos are generated by `src/lib/foot/synthetic.ts`; no third-party photos are shipped.
Verify licences from each package's own `package.json`/repository before redistribution; this table is a summary, not legal advice.
