# Testing

* `cd services/document-ocr && pip install -r requirements-dev.txt && pytest` (45 tests, about 35 s, no downloads):
  * **Rules** (`test_extract.py`): every date format, ambiguity, amounts needing a currency or money label, key-values, things that must **not** become fields (clock times, URLs, page numbers), confidence and flag propagation, exact versus approximate field boxes, separate label/value items, arithmetic checks passing and failing, classifier saying *unclassified*.
  * **Real files** (`test_documents.py`): the text PDF read back character for character; item boxes land on rendered ink; fields equal the ground truth; tables recovered exactly (text PDFs) and ≥ 18 of 20 cells on the simulated scan (20 measured); skew found within 0.3° of the 1.4° applied; character error rate ≤ 3 % (0.9 % measured) with an order-insensitive approximate-substring metric; OCR of a clean render; TIFF scan; multi-page TIFF; embedded-only on a scan; sensitivity; page range; truncated/junk/encrypted/oversized/too-many-page inputs; cancel; the searchable PDF re-opened and searched with pdfium.
  * **API** (`test_api.py`): validation by content, limits, id and file-name safety, gating before results, parameter validation, full flows on the text and scanned samples, field correction with the original preserved, document review, every export, delete, cancel and the store limit.
* `npm run test:documents:ui` (Playwright; `MODE=static` without the service, `MODE=server` with it): notice and empty states, invalid uploads, boxes equal the service's items and the field box covers ink in the browser's own pixels, search and page jumps, zoom and layer toggles, editing with the original kept and stored by the service, confirm/reject/approve, table grid, all exports, the OCR path (confidence on every line, red low-confidence boxes, skew report), embedded-only on a scan, uploading a TIFF from disk with no invented fields or tables, phone layout.
