# Demo 22: Architectural Geometry Intelligence

Route: `/cad-bim-suite/architectural-geometry-simplification` (app at `/app`). Listed under CAD/BIM. Runs entirely in the page; no backend.

## What is real and what is simulated
- **Simulated:** the CAD import. The building is generated by `src/lib/geomsimp/model.ts` (three storeys, layered walls, framed windows, doors, partitions, roof with parapet, overhangs, trees, neighbours). Nothing is read from Revit or SketchUp.
- **Real, computed from that geometry:** classification (`classify`), solid-to-surface conversion, mid-plane extraction, coplanar merging with an exact-tiling check, azimuth and tilt, zone enclosure checks, the dependency-aware cache (`planUnits` / `runUnits`), validation and the JSON export. Timings use `performance.now()` in your browser and are labelled as such.
- **Not done:** thermal, solar or daylight simulation.

## Incremental updates
Every element and every zone is a cache unit with an `own` fingerprint (its parameters) and a `dep` fingerprint (what it reads from others: a window reads its host wall; a wall reads its openings; a zone reads the portion of each bounding wall that touches it, plus the ceiling above). Changing a window recomputes the window, its host wall and the zone it sits in. The test suite checks that the incremental result equals a full rebuild.

## Tests
`npm run test:geomsimp` (engine: counts, areas, orientation, exact incremental sets, export) and `npm run test:geomsimp:ui` (Playwright against a running production build, `BASE=http://localhost:3011`).
